# 教务 / 校园网接口说明

> 本文所有结论来自对 `https://jwglxt.haut.edu.cn` 的**实际请求**，不是推测。
> 接口属于学校内部 AJAX 接口，随正方版本升级可能变化 —— 这也是本项目坚持
> 「原始报文落盘 + 宽松解析」的原因。

## 1. 系统形态

| 项 | 结论 |
|---|---|
| 教务系统 | 正方新版（`zftal-ui-v5-1.0.2`，页面 meta `Copyright=zfsoft`） |
| 入口 | `https://jwglxt.haut.edu.cn/jwglxt/xtgl/login_slogin.html` |
| 上下文路径 | **所有接口都带 `/jwglxt` 前缀**，漏了就是 404 |
| 对外可达 | 公网可直接访问，不需要校园网 / VPN |
| 登录方式 | ① 学号 + 教务密码（本项目采用） ② 统一身份认证 CAS ③ 微信扫码 |
| 图形验证码 | `dlsfbxyzm=0` → 默认关闭（连续输错可能触发，需要兜底） |
| 密码传输 | `mmsfjm=1` → RSA 加密（`RSA/ECB/PKCS1Padding`，base64 输出） |
| 错误次数控制 | `yzcskz=3` |

## 2. 登录握手

```
1) GET  /jwglxt/xtgl/login_slogin.html
        → Set-Cookie: JSESSIONID=...
        → <input id="csrftoken" value="<uuid>,<uuid去横线>">
        → 同时拿到开关：dlsfbxyzm / mmsfjm / yzcskz / sfxswechatlogin

2) GET  /jwglxt/xtgl/login_getPublicKey.html?time=<ms>
        → {"modulus":"AILTH3e8...","exponent":"AQAB"}   （均 base64 大端）

3) 本地 RSA:
        n = BigInt(b64dec(modulus));  e = BigInt(b64dec(exponent))
        mm = base64(RSA_PKCS1v15(密码, n, e))

4) POST /jwglxt/xtgl/login_slogin.html?time=<ms>
        Content-Type: application/x-www-form-urlencoded
        yhm=<学号>&mm=<上一步>&csrftoken=<整串>&language=zh_CN

5) 校验会话: GET /jwglxt/xtgl/index_initMenu.html
        若仍 302 到 login_slogin.html 则失败
```

### 三个踩过的坑

1. **`csrftoken` 必须整串提交**（`uuid,去横线uuid`）。正方前端是原生 `form.submit()`，
   不做任何拆分；只提交后半段会被判失败。
2. **登录是 302 跳转**。用自动跟随重定向的 HTTP 客户端会丢掉那一跳的 `Set-Cookie`，
   会话就断了 —— 必须手动接管（`followRedirects = false`）。
3. **密码错误时返回的是 200 + 登录页 HTML**，内容含「用户名或密码不正确」，
   不是 4xx，只能靠内容判定。

## 3. 数据接口

未登录访问均 `302 → login_slogin.html`（路由存在；不存在会 404）。

| 功能 | 接口 | 关键参数 |
|---|---|---|
| 课表 | `POST /jwglxt/kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151` | `xnm`(学年) `xqm`(学期) `kzlx=ck` |
| 考试安排 | `POST /jwglxt/kwgl/kscx_cxXsksxxIndex.html?doType=query&gnmkdm=N358105` | `xnm` `xqm` + queryModel 分页 |
| 成绩 | `POST /jwglxt/cjcx/cjcx_cxDgXscj.html?doType=query&gnmkdm=N305005` | `xnm` `xqm` + queryModel 分页（`showCount=200`） |
| 学期列表 | `GET  /jwglxt/cjcx/cjcx_cxDgXscj.html?gnmkdm=N305005` | 从页面 `<select id="xnm">` 解析 |

`xqm` 取值约定：`3` = 第一学期，`12` = 第二学期，`16` = 第三学期。

### 又两个坑

4. **课表不传 `xnm/xqm` 直接返回 `null`**（不是报错，是静悄悄地给你个空）。
   所以 App 必须自己先算出当前学期（按月份推：8 月起算新学年第一学期，2–7 月算第二学期）。
5. **成绩接口不是 `cjcx_cxXsgrcj.html`** —— 那个地址在本校部署下是 404「系统维护页面」。
   真实可用的是成绩总览页的 jqGrid 数据接口：`cjcx_cxDgXscj.html?doType=query`。

课表返回体里的 `xsxx` 带学生姓名 / 学号 / 班级 / 专业，
是「登录后立刻知道我是谁」最省的取法；但它**不返回当前教学周**（`DQZ` 字段在本部署下缺失），
所以周次要靠校历推算（见 `lib/core/term_calendar.dart`）。

## 4. 校园网认证

| 项 | 值 |
|---|---|
| 认证系统 | 深澜 srun（Srun3k） |
| Portal | `http://<gateway>:<port>/cgi-bin/srun_portal` |
| 接口 | `POST action=login&n=117&type=3&ac_id=<id>&mac=02:00:00:00:00:00&username=..&password=..&drop=0&pop=1` |
| 用户名加密 | 每个字节 +4，前缀 `{SRUN3}\r\n` |
| 密码加密 | 与 `1234567890` **逆序**逐位 XOR；低 4 位 +0x36、高 4 位 +0x63；按索引奇偶交替拼接 |
| 成功判定 | 返回 JSON 里 `error == "ok"` 或 `res == "ok"` |

### 网关地址不能写死

不同校区 / 楼栋的 IP 段完全不同（例：`172.33.x.x` 网段、路由器 `172.33.191.254`）。
本项目在运行时自动识别，三路兜底（`android/.../PortalProbe.kt`）：

1. 打系统探针地址（`generate_204`），看被 302 跳到哪 —— 那个 host 就是认证网关，
   顺带从跳转 URL 里抠出 `ac_id`；
2. 不行就拿链路默认网关，试 `69 / 80 / 8080` 三个端口；
3. 都不行才用用户手填的地址。

### 请求必须绑定 WiFi 网络

手机同时开着 5G 时，安卓会把请求交给「已验证联网」的那张网卡。
校园 WiFi 未认证 → 系统判它不通 → 请求从移动数据发出去打内网 IP → 必然 `SocketTimeoutException`。
必须用 `Network.openConnection()` 显式绑定到 WiFi 网络。

明文 HTTP → Android 必须开 `usesCleartextTraffic`。

## 5. 已知风险

- 正方接口是内部 AJAX 接口，学校升级后字段可能变 → 必须「原始报文落盘 + 宽松解析 + 缺字段不崩」。
- 连续密码错误 3 次有锁定风险 → 登录失败要有次数提示与冷却。
- 教务账号密码是强凭据 → **App 不存明文密码**，只存加密后的会话 Cookie，且支持一键登出清空。
